# Algas combustíveis e materiais

Aula visual de 60 minutos para 2º e  3º anos de Engenharia Bioquímica. Versão principal em português brasileiro.

- [Apresentação](https://molino-algae.github.io/algae-sustainable-future/)
- [Guia notas e Anki](https://molino-algae.github.io/algae-sustainable-future/materiais.html)
- [Fontes e cálculos](https://molino-algae.github.io/algae-sustainable-future/materiais/auditoria/)
- [Arquivo em inglês](https://molino-algae.github.io/algae-sustainable-future/archive/en-2026-11-08/)

Site estático com Reveal.js. GitHub Pages publica main/raiz. O formulário anônimo e o jogo continuam no site JUSTLAB. O painel consulta o serviço existente a cada 3 segundos. Dados e histórico permanecem nesse serviço; este repositório não guarda respostas de estudantes ou chaves de gestão.

As fotografias e figuras fornecidas têm créditos específicos em CREDITS.md e nas notas. Dados quantitativos, cálculos, unidades e limites estão na auditoria. Os gráficos novos têm rótulos em português; imagens científicas preservam identificadores originais com explicação traduzida. A série histórica OWID foi baixada em 8/11/2026 e recortada para 1800–2023; o retrato energético 2022 é separado.

O arquivo em inglês é histórico e pode conter números corrigidos na edição atual. Não usar como versão didática mais recente.
